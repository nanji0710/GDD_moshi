## 2. 关键交互决策（已实现）

1. **改装页 = 暂停**。理由：空格键本来就是零成本暂停，改装暂停不新增漏洞；「不暂停」要额外付出增量更新、z-index、遮挡补偿三份工。`GDD:863` 只承诺站台购物暂停；`08-交互` 把「战斗中实时改装」列为反模式。
2. **FAB 单一谓词**：抽屉完全隐藏才出现。不按 `drawerState` 枚举（枚举是错的根源）。
3. **模态栈**：同一时刻最多 1 个模态；`确认框 > 抽屉`；三选一是强制选择，Esc 不留口子；关闭后焦点回触发元素。
4. **竖屏**：进局给一次性「横屏更好开」，可一键继续竖屏；转横屏自动消失；不强制遮罩到无法游玩。
5. **弹窗位置**：toast 顶栏下沿动态定位（竖屏三行 HUD 不再盖住统计）；面板打开时旧提示清空、新提示走底部；抽屉打开时车厢条/技能条让位，避免「同一份编组画三遍」。

## 3. 自动化验收（`prototype/tools/smoke.mjs`）

- **A1 工具隔离**：随机空闲端口（`net.listen(0)`）+ 每次运行 nonce（页面 URL 与 `user-data-dir` 都带）+ Windows 进程树 `taskkill /T /F`；串行与并发双跑互不串台。
- **A2 移动端「收起」**：站台抽屉 ✕ 可收起且不触发 `departStation`；FAB 常驻可回站台。
- **A3 截图 manifest**：每张截图记录 `id/file/width/height/dpr/sha256/at`。
- **B1 命中**：改装抽屉内每个 `.witem/.btn` 中心 `elementFromPoint === 自身`，被遮挡数 0。
- **B2 热区**：抽屉/站台内可点元素 ≥44×44（含关闭、编组行、◀▶、✕、出发）。
- **B3 暂停一致性**：`drawerState==='refit' && state==='run'` 时 2.1s 里程增量严格 `=== 0`；3× 倍速关闭后恢复；手动暂停不被吞。
- **B4（缓解，不列硬验收）**：重伤重建保 `scrollTop`；暂停期间不因掉血重建。全量增量更新排期见 §6。
- **U1**：下一站 = 里程碑 − 当前（5 km / 19 km 两例）。
- **U2**：未解锁城市名与 `.sub` 对比度脚本实算 ≥4.5。
- **U3**：三选一按 `2` 键选中且车辆 +1。
- **布局**：1500×860 / 1024×768 / 390×844 的站台、改装、三选一、设置、地图、结算，面板 rect 不出视口、抽屉正文无横向溢出、顶栏无横向溢出；console 0 报错。

## 5. 已知取舍

- 竖屏不做等宽重排：车厢条仍横向滚动，但新增「还有 N 节 →」提示 + 一次性横屏建议。理由：等宽重排会改动战斗 HUD 的节奏信息密度，收益低于风险。
- 抽屉关闭钮与「完成」按钮并存：X 用于快速收起，底部「完成」用于读完内容后的明确退出；两者都不触发出行。
- 地图节点避让只影响显示坐标，不影响 `data-level`、解锁顺序与点击判定。
