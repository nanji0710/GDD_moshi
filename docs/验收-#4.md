## 4. 发布包

- 生成命令：`node tools/package-release.mjs`（仓库根；零依赖，与 `tools/stage-site.mjs` / CI 共用 `tools/release-manifest.mjs` 白名单）
- 产物：`release/last-train-prototype.zip`
- 项数 / 字节：**27 项 / 322,764 B（315.2 KiB）**
- sha256：`419cfc60a754f3032cafa45d2a2eafdd749c934852809c9c6765bf19b6b42581`
- 可重复性：连跑两次 sha256 完全相同；ZIP 内时间戳固定 1980-01-01、条目按路径排序、deflate level 9
- 与旧包（`323,531 B` / sha256 `8be2745b…74eb`）的差异：同一批 27 个文件，旧包由 `Compress-Archive`（.NET deflate）生成；新打包器改为可重复实现后体积小 767 B，内容逐文件一致
- 解压后根目录即 `index.html`；`zip6-play.log` 记录解压副本的 CDP 实点结果（console 0 / 404 0 / CORS 0 / 到站台）
