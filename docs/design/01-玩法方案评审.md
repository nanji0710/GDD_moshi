# 11 · 玩法方案评审（第三轮）

> 评审对象：你提出的「局内循环 / 车厢与武器 / 结算与局外 / 地图与美术」四组设计

> 评审标准：**能不能做完** > **好不好玩** > **好不好看**。达不到第一条的，后面两条都不算数。

## 0. 总评：这套方案能落地，但有 3 个必须先补的洞

**整体判断：成立，而且比上一轮讨论的"武器合成进化"更收敛、更适合一人做。**
理由：你把系统从"组合爆炸"（合成 × 进化 × 词条）拉回到"线性成长 + 分支选择"，内容量从 O(武器²) 降到 O(武器 × 2~3)，这是对的方向。

但有三处会直接决定"这游戏能不能玩 10 分钟以上"：

| # | 洞 | 后果 | 补法 |
| --- | --- | --- | --- |
| **D1** | **被迫停车修复 = 纯罚站** | 修复 15 秒里玩家只能看着被咬，这是挫败不是紧张 | 修复改成**可操作**（3 次敲击，或用废料加速），停车期不做无限刷怪 |
| **D2** | **结算只看损耗** | 玩家会"龟"：不开火、不冒险、能绕就绕，游戏变得被动 | 结算必须有**正向项**：难民存活、里程、Boss、完美护送 |
| **D3** | **车厢只增不减且越重越慢** | 越到后期越惩罚，与"难度递增"叠加成双重负担；且"不拿车厢"变成最优解 | 给三个出口：动力车厢对冲、可丢弃车厢、以及"必须有 N 节人员车厢才能接走站台难民"的关卡门 |

三个技术确认（都查了源码/数据，不是猜的）：
- ✅ **54 城地图可以直接用**，而且 `geo_*.js` 里**本来就有 `rail` 图层**（`js/geo.js:45` 的 `KEYS` 含 `rail`），真实铁路走向 + 桥 + 隧道 + 车站天然就是关卡轨道。这是整套方案里最值钱的一条。
- ✅ 关卡只需切城市的一条走廊，数据量可降到原文件的 10–20%。
- ⚠️ geo 坐标精度是 1/64 格 ≈ 3.9 m，折线需要再平滑一次，否则轨道会有折角。

## 1. 局内循环

### 1.1 护送难民 —— 方向对，但"难民"现在还是个数字

**评估：✅ 成立，且是这套设计的情感核心。** 它解决了"我为什么要跑"这个问题——不是"活下去"，是"把人送到"。

但你的描述里缺三件事，不补的话难民就只是个"结算乘数"，玩家不会真的在意：

| 缺口 | 建议 |
| --- | --- |
| 难民**怎么上车** | 补给点（避难所/废弃车站）有等待的难民，**停下才能接**（3–8 秒），接人期间丧尸会来——这就把"接人"变成一个紧张时刻 |
| 难民**怎么死** | ① 人员车厢被摧毁 → 该车厢的人全死；② 感染（特定丧尸攻击后 20 秒内不处理 → 该车厢人 -1）；③ 主动征召去操作炮塔 → 有死亡概率 |
| 难民**有什么用** | 别只当结算货币。给两条：**① 征召为炮手**（该车厢 +15% 射速，但有 8% 死亡概率）；**② 人多能开"士气 buff"**（≥10 人时全车装填速度 +10%） |

**失败条件建议**：
- 主失败：车厢全毁 / 燃料耗尽被围。
- 软失败：**难民死光**——不直接结束，但本局结算清零，且不能进入下一关。这比"直接死"惩罚柔和，又足够疼。

**数值草案**：
```
人员车厢容量 12 人
接人耗时 3 s + 0.25 s/人（接 12 人要 6 s）
每存活 1 人 = 40 里程点（结算货币）
完美护送（0 死亡）+30% 加成
```

### 1.2 资源与补给点 —— 只留一种局内货币

**评估：✅ 方向对，但"兑换资源"这个说法要收敛。**
你说"打丧尸获得资源，并在补给点兑换资源、购买 buff"。如果局内有 2 种以上货币（废料 + 补给券 + 油票），玩家会算不过来，而且你也没有 UI 预算。

**建议：局内只有 1 种货币「废料」**，补给点做 5 件事：

| 补给点服务 | 价格（废料） | 说明 |
| --- | --- | --- |
| 补弹药 | 75 / 300 发 | 每站最大单项开支，逼你算"这把枪吃不吃得起" |
| 加油 | 55 / 25% | 满油续航必须 < 单关里程（中途至少加一次） |
| 修车 | 0.6 / 点耐久 | 越晚修越贵（因为要修的车厢更多） |
| 买 buff | 60–150 | 见下表，**本关剩余时间生效** |
| 接难民 | 免费 | 但接人要时间，且会引来丧尸 |

**Buff 池（6 个，别多）**：

| Buff | 效果 | 价格 |
| --- | --- | --- |
| 弹链加速 | 全车射速 +15% | 120 |
| 穿甲弹 | 全车对精英/Boss 伤害 +25% | 150 |
| 备用油箱 | 燃料消耗 -30% | 90 |
| 临时装甲 | 本关首次车厢损毁时免伤一次 | 140 |
| 老练扳手 | 修复速度 +50% | 70 |
| 顺风 | 最高速度 +12% | 60 |

> 注意：buff 不要做成"永久成长"，否则局内的经济决策会被抵消。**本关生效、下关清空**，这是让"补给点"每关都有意义的关键。

### 1.3 轨道损坏与被迫停车 —— ⚠️ 这是全案最大的坑（D1）

**评估：机制正确，执行方式危险。**
"轨道损坏 → 被迫停车 → 修复 → 继续"这条链在纸面上很自然，但实际玩起来会变成：

```
停车 → 丧尸围上来 → 你什么都做不了 → 15 秒后修好 → 车已经在掉血
```

玩家会觉得"这不是我打的，这是游戏在罚我"。而且如果停车期间照常刷怪，还会出现"故意停车刷资源"的反向利用。

**三种修法，我推荐第 3 种：**

| 方案 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| A 纯等待 | 15 s 倒计时 | 最简单 | 罚站，劝退 |
| B 小游戏 | 按节奏点 3 次（每次修 1/3） | 有参与感 | 需要一套新 UI，且会打断节奏 |
| **C 资源抉择（推荐）** | 修复需要**人手**：每按一次「派人修轨」消耗 1 名难民/工兵，3 人 12 秒修好；没有人手就只能等 40 秒，或者花 200 废料「临时加固」 | 复用你已有的"难民"资源，产生道德压力（"派谁去？"），且不需要新 UI | 需要定义"人手" |

**推荐落地版**：
```
轨道耐久 100
撬轨者每只每秒 -11（沿用原型）
损到 60 → 限速 60%；损到 100 → 强制停车
停车后：修轨进度每秒 +8（自动），按「派人」每次 +25（消耗 1 人手，最多 3 次）
人手 = 难民数 ÷ 4（向下取整，满员 12 人 = 3 人手）
修轨期间：丧尸刷新率 -60%（避免罚站刷资源），但已有丧尸继续咬
```

**路况也要做出层次**（你说"速度受路况影响"）：
| 路况 | 触发 | 最高速度 | 视觉 |
| --- | --- | --- | --- |
| 正常 | 默认 | 100% | — |
| 积水/碎石 | 随机区段 | 75% | 地面水洼/碎石 |
| 被撬 | 撬轨者 | 60% → 强制停 | 铁轨翘起 + 火星 |
| 断桥前 | 关卡设计固定 | 40%（限速通过） | 桥面塌陷 |

### 1.4 难度递增 —— 公式化，别用手感调

**评估：✅ 方向对，但"丧尸生命/攻击同步递增"这一条要小心。**
如果 HP 和 ATK 同时线性涨，玩家会同时失去"打得动"和"扛得住"两种能力，难度会**指数级**上升，第 4 关就崩。

**建议：HP 涨、ATK 少涨、数量涨得最慢。**

```
第 n 关（n=1..12）：
  里程      = 8 + 1.5×(n-1)        km        （8 → 24.5 km）
  丧尸 HP   = 42 × (1 + 0.30×(n-1))           （42 → 181）
  丧尸 ATK  = 7 × (1 + 0.12×(n-1))            （7 → 16.2）
  精英比例  = 2% + 1.2%×(n-1)                  （2% → 15%）
  同屏上限  = 120 + 18×(n-1)                  （120 → 318）
  波次间隔  = 28 - 1.2×(n-1) 秒                （28 → 15 s）
```

为什么这样分配：
- **HP 涨 3 倍**：让"武器升级"有存在意义（否则 3 级武器打穿全游戏）。
- **ATK 只涨 1.3 倍**：车厢耐久是玩家的"容错预算"，涨太快会让一次失误直接结束。
- **同屏涨得慢**：同屏数量受性能与可读性双重限制（原型数值上限 260，实测 140 只时流畅；上到 200+ 需要先做空间索引与绘制合批，见 [06 文档 §1 D2](../inspire/06-GitHub开源参考.md)）。
- **波次间隔缩短**：这是最便宜的"变难"手段，且不会让单次战斗变长。

**关卡长度与一局时长**：8 km @ 24 m/s ≈ 5.5 min + 停车/补给 ≈ **7–8 分钟/关**。12 关 = 一章 90 分钟，正好。

### 1.5 Boss —— 别做成"血厚的丧尸"

**评估：✅ 必须有，但 Boss 是**机制**，不是数值。**
"每关中后期一个 boss"如果只是 HP ×20、伤害 ×5，那就是一个 DPS 检查，玩家会觉得"我在打木桩"。

**建议：位置固定（关卡 72% 处，即里程的 0.72），三种类型轮换，每种考一个能力：**

| Boss | 考什么 | 机制 | 出现在 |
| --- | --- | --- | --- |
| **装甲者**（重甲巨尸） | 穿甲/电磁 | 正面护甲减伤 70%，必须从背后/用穿甲武器打；倒下前会撕开一段轨道 | 第 1、4、7、10 关 |
| **召唤者**（尸母） | 目标优先级 | 不停召唤小怪，自身躲在远处；不打断就一直刷 | 第 2、5、8、11 关 |
| **拆轨者**（巨型工程尸） | 停车的应对 | 高速冲向车头，撞上就强制停车 + 立即刷一波；必须用高 DPS 在它贴上之前打掉 | 第 3、6、9、12 关 |

**Boss 必须在"行驶中"打**，不要让它变成"停车打 Boss"——否则和你 1.3 的停车机制重复，节奏会变成"停-打-停-打"。

### 1.6 技能卡投放 —— 你让我把握，这是我的排期

**评估：✅ 开局没有、随关卡获取，这个思路很好**（避免了"开局三张卡，玩家不读"）。

但要注意：**技能卡是"决策"，不是"奖励"**。纯发放会让玩家只当它是新按钮；给"三选一"才会产生 build 感。

```
第 1 关：无技能（教学：先学会看路、跑、装武器）
第 2 关：固定给「紧急制动」（第一次必须停车/避让）
第 3 关：固定给「全弹齐射」（第一次遇到成群挡路）
第 4 关：固定给「强制过载」（第一次遇到 Boss）
第 5 关起：每关开始三选一（从未拥有的池子里选 1 张）
        池子 6 张：紧急制动 / 全弹齐射 / 强制过载 / 烟雾弹（降低仇恨 8 秒）/ 
                  速修（立即修 50 轨道）/ 诱饵（把尸群引到车尾 10 秒）
冷却：30 / 45 / 60 秒三档（按强度）
局外：可以花里程点"多带 1 张卡"（最多 3 张）
```

## 2. 车厢与武器

### 2.1 车厢获取节奏 —— ⚠️ 有退化风险（D3）

**评估：方向对（成长 + 变慢的张力），但存在一个明显的退化解：**

> 如果"车厢只增加、越重越慢、且没有强制需求"，那么**最优解是尽量少拿车厢**——车轻、跑得快、少挨打。玩家会在第一关就发现这一点，然后整个"编组"系统就废了。

**三个补丁，建议全上：**

| 补丁 | 做法 |
| --- | --- |
| **① 必须有车厢才能赢** | 站台难民数量 > 单节人员车厢容量（12 人），后期一关要接 30+ 人 → 你必须 3 节人员车厢 |
| **② 给"快"一个出口** | 新增**动力车厢**：最高速度 +10%、加速度 +20%，抵消 1.5 节车厢的惩罚 → 想快就得占一节 |
| **③ 给"扔"一个出口** | 补给点可以**丢弃车厢**（换 300 废料），但丢掉的人/武器一起没 |

**具体节奏（我拍的数）**：
```
起始：车头（1 挂点）+ 1 节人员车厢（1 挂点）= 开局只有 2 个挂点，火力很紧
第 1 节：行驶 1.2 km 后（第一站前），三选一：武器/动力/人员
之后：每 1.5 km 获得 1 节，三选一
单关上限：8 节（含车头）
速度惩罚：每节 -5%（累乘），最低 55% 最高速
动力车厢：+10%（可叠，最多 2 节）
8 节满编 @ 34 m/s → 34 × 0.95^7 × 1.2 ≈ 28.5 m/s（还在可玩区间）
```

> 注意：**"车厢越多越慢"必须让玩家看得见**。HUD 上加一个"重量/速度"读数：`8 节 · 22.4 m/s（-34%）`，否则玩家会以为是 bug。

### 2.2 车厢类型（5 种，别再多）

| 车厢 | 作用 | 挂点 | 代价 |
| --- | --- | --- | --- |
| **人员车厢** | 载 12 难民，提供 3 人手 | 1（顶部机枪位） | 无 |
| **武器车厢** | 2 个武器挂点 | 2 | 重 |
| **动力车厢** | 速度 +10%、加速度 +20% | 0 | 无火力 |
| **装甲车厢** | 自身耐久 ×2；相邻车厢受击 -40% | 1 | 慢 |
| **修理车厢** | 每 3 秒修相邻车厢 8 点；修轨速度 +100% | 0 | 无火力 |

> 一开始只给 3 种（人员/武器/动力），装甲和修理在第 4 关后解锁——**解锁本身就是奖励**。

### 2.3 武器 10 级 + 分支 —— 数学上可行，但要控制"内容爆炸"

**评估：✅ 不做合成是对的**（合成需要两把满级武器，而你是"逐级成长 + 分支"，两者语义冲突）。
但"每 3 级出现两个方向"= Lv3 / Lv6 / Lv9 各一次 → **每个武器 2³ = 8 个终态**，5 把武器 = **40 个终态**。这不是一个人能做完的（每个终态都要有独特表现和平衡）。

**解法：分支不产生新武器，只产生"机制修饰符"。**

```
Lv1–3：基础武器（只涨数值）
Lv4  ：第一次分支（2 选 1）——决定"这把枪走哪条路"
Lv5–6：数值强化
Lv7  ：第二次分支（2 选 1）——在已选的路线上再特化
Lv8–9：数值强化
Lv10 ：终极强化（机制不变，外观 + 数值 + 被动）
```

每个分支选项都是**复用已有机制 + 改参数**，不是新武器：

| 武器 | Lv4 分支 A | Lv4 分支 B | Lv7 A→A | Lv7 A→B | Lv7 B→A | Lv7 B→B |
| --- | --- | --- | --- | --- | --- | --- |
| **机枪** | 双联装（射速 ×1.8，伤害 ×0.6） | 重弹（伤害 ×1.6，射速 ×0.7） | 弹幕（+2 目标） | 穿甲（无视 40% 护甲） | 点射（暴击 +25%） | 压制（命中减速 20%） |
| **喷火** | 广域（锥角 52→80°，射程 -20%） | 聚焦（射程 +40%，锥角 -40%） | 火墙（地面留 3 s 火） | 熔穿（对装甲 +60%） | 长喷（射程 ×1.6） | 爆燃（死亡爆炸） |
| **近防** | 高频（射速 ×1.5，伤害 ×0.7） | 重炮（单发 ×2.2，射速 ×0.5） | 扫射（扇形 3 目标） | 破甲（对 Boss +50%） | 狙击（暴击 3×） | 干扰（命中降攻） |
| **电磁** | 链式（连锁 +2） | 过载（范围击晕 1.5 s） | 电网（留 2 s 电场） | 熔断（对机械 ×2） | 脉冲（每 5 发一次全屏） | 静滞（减速 40%） |
| **迫击** | 集束（3 发小范围） | 重型（单发 ×2，范围 ×1.5） | 燃烧弹（地面火） | 穿甲弹（对建筑） | 烟幕（降仇恨） | 震荡（击退） |

这样内容量是 **5 武器 × 2 分支 × 2 次 = 20 个"节点"**，且每个节点只是改 2–3 个数 + 换颜色，**可以做完**。

**升级成本曲线**（资源逐级增多，你说的）：
```
cost(n) = 25 × 1.30^(n-1)
→ 25, 33, 42, 55, 71, 93, 121, 157, 204, 265（累计升到 Lv10 = 1066 废料）
第 1 关收入 ≈ 1200  → 刚好能养满 1 把
第 12 关收入 ≈ 4000 → 能养 3 把满级 + 补给
```
> 两个都别调：如果 cost 基数升到 60，第 1 关连一把都养不满；如果收入翻倍，8 个挂点就会全塞满，"选择"消失。
> 这个"装不满"是刻意的：**一局最多把 2–3 个挂点练起来**，剩下的位置只能放 1 级武器当填线。

### 2.4 一局的资源账（验证你的设计能不能自洽）

| 项 | 每局（第 1 关，8 km） |
| --- | --- |
| 击杀收入 | 约 900 只 × 1 废料 = 900 |
| 站台结算/任务 | 400 |
| 完美护送奖励 | 300 |
| **合计收入** | **≈ 1600** |
| 弹药补给（3 站） | 300 |
| 燃料（3 站） | 165 |
| 修车 | 200 |
| 买 buff（2 个） | 240 |
| **净可支配** | **≈ 695** |

695 废料能做什么：
- 两把武器各升到 **Lv6**（319 × 2 = 638）
- 或一把武器冲到 **Lv8**（累计 597）
- 或新装 3 把 1 级武器（25 × 3 = 75）+ 留出升级余量

**结论：收入结构自洽，但它要求"资源每关重置"。**
如果资源跨关累积，第 3 关就会资金溢出、第 4 关开始无脑升级、第 6 关之后所有武器满级——难度曲线直接失效。
→ **资源必须每关清零**（剩下的按 0.5 折算成里程点，见 §3.1）。这也正是你"剩余资源折算局外奖励"那条设计真正的意义：它不是奖励，是**防止通货膨胀的泄压阀**。

## 3. 结算与局外

### 3.1 结算 —— 必须有正向项（D2）

**评估：⚠️ "根据车辆与人员损耗结算"这一条如果单独存在，会导致玩家龟缩。**
纯扣分制会让理性玩家选择"最安全路线"：不开火（省弹药）、不接人（省风险）、能绕就绕（省时间）。游戏会变被动。

**建议的结算公式（加法，不是减法）**：

```
基础分 = 里程km × 100
护送分 = 存活难民 × 40
战斗分 = 击杀 × 0.5 + Boss × 300
完美分 = 无车厢损毁 200 / 无难民死亡 150
剩余折算 = 剩余废料 × 0.5 + 剩余弹药 × 0.1 + 剩余燃料 × 2
扣分项 = -车厢损毁 × 120
─────────────────────────────────
局外里程点 = (基础 + 护送 + 战斗 + 完美 + 剩余折算 - 扣分) × 难度系数
```

**算一遍第 1 关（8 km、36 难民、900 击杀、1 Boss、0 损毁）**：

| 项 | 分值 | 占比 |
| --- | --- | --- |
| 里程 | 800 | 17% |
| 护送（36 人） | 1440 | **31%** |
| 战斗（900 击杀 + Boss） | 750 | 16% |
| 完美（两项都拿） | 350 | 7% |
| 剩余折算（~700 废料等） | 350 | 7% |
| 车厢损毁 | 0 | — |
| **合计** | **≈ 3690** | |

要点：
- **难民是最重的一项（约 1/3）**，保证"护送"是主玩法而不是"射击"。
- **剩余资源按比例折算**（你说的，对的），但比例要低（0.5），否则玩家会"攒着不用"。
- **车厢损毁扣分要重**（-120/节，约等于 3 个难民），否则玩家会把车厢当耗材。

### 3.2 局外 —— 只卖"选择"和"外观"，别卖数值

**评估：✅ 局外升级列车/武器/皮肤是标准做法，但有一条红线。**
如果局外能直接买"武器伤害 +10%"，那么第 8 关的难度就会被"氪/肝"抹平，你会失去对难度曲线的控制。

**建议的三类局外内容**：

| 类别 | 内容 | 为什么安全 |
| --- | --- | --- |
| **解锁** | 新武器种类、新车厢类型、新技能卡、新关卡 | 增加选择，不直接加数值 |
| **容量** | 初始挂点 +1、初始技能卡槽 +1、起始废料 +200 | 有上限，且是"起手更顺"而非"后期更强" |
| **外观** | 列车涂装、车厢皮肤、烟囱颜色、Boss 图鉴 | 纯氪金/收集，无平衡风险 |

价格参考：解锁一把武器 = 800 里程点（约 2–3 局），皮肤 = 300–600。

## 4. 地图与美术

### 4.1 54 城地图 —— ✅ 技术上完全可行，而且是全案最值钱的一条

我核对了 `city-and-metro/js/geo.js:45`，geo 数据的图层是：

```
names / water / waterLines / roads / streets / rail / parks / reserves / woods / ...
```

**`rail` 图层就是真实铁路线**（含站场、支线）。这意味着：

| 你的需求 | 现成的数据 |
| --- | --- |
| 关卡轨道 | `geo.rail` 的真实走向（有弯道、有桥、有隧道口） |
| 跨江/跨谷 | 铁路线与 `water`/地形求交，自动得到桥段 |
| 车站/补给点 | `rail` 的站点 + `roads` 交汇处 |
| 废墟城市底图 | `buildings`/`roads`/`parks` 全都有 |
| 关卡差异 | 54 城 × 每城不同的地形（沿海/山地/平原） |

**怎么做（三步）**：

1. **切走廊**：以一段真实铁路为中心线，取 ±800 m 的带状区域（约 1.6 km 宽 × 8–14 km 长）。只保留落在走廊内的要素 → 数据量从 0.3–2 MB 降到 **50–300 KB/关**。
2. **平滑轨道**：geo 坐标精度 1/64 格 ≈ **3.9 m**，直接用会有折角 → 过一遍 Catmull-Rom（原型里 `util.js` 的 `U.spline` 就是干这个的）。
3. **废墟化**：不改几何，只改渲染配色 + 加"破损系数"（见 4.2）。

> ⚠️ 许可：OSM 数据是 ODbL，**可以商用**，但要求署名 + 衍生数据库同样以 ODbL 开放。你切出来的关卡走廊属于"衍生数据库"，需要一起开放（放在仓库里即可，不影响你的代码闭源）。

### 4.2 废墟化改造清单（不用重做几何）

| 要素 | 现在（城市） | 改成（废墟） | 工作量 |
| --- | --- | --- | --- |
| 建筑配色 | 浅蓝灰玻璃 | 深灰 + 焦黑 + 破口 | 配色表 1 天 |
| 建筑轮廓 | 完整矩形 | 部分楼体"缺角"（随机切掉一个角） | 2 天 |
| 道路 | 白色路网 | 龟裂 + 废弃车辆 + 路障 | 1 天 |
| 绿地 | 公园绿 | 荒草 + 枯树 | 0.5 天 |
| 水面 | 蓝 | 黑绿 + 漂浮物 | 0.5 天 |
| 灯光 | 无（白天） | 火光/车灯/信号灯 | 1 天 |

**关键判断**：不要重画地图，**只改配色 + 加破损**。这是 3 天 vs 3 周的差别。

### 4.3 列车美化（程序化，不加贴图）

| 项 | 做法 | 价值 |
| --- | --- | --- |
| 车厢类型可见 | 每类型一个剪影：人员车厢有窗、武器车厢有炮座、动力车厢有烟囱、装甲车厢厚重、修理车厢有机械臂 | ★★★ 玩家能"读"自己的编组 |

| 受损可见 | 装甲板脱落 → 冒烟 → 起火 → 车窗破碎（4 阶） | ★★★ 心疼 |
| 编组长度的重量感 | 车厢越多，车尾摆动越明显（视觉晃动的幅度与节数成正比） | ★★ 速度感 |

## 5. 冲突清单（你的方案内部互相打架的地方）

| # | 冲突 | 表现 | 解法 |
| --- | --- | --- | --- |
| 1 | **停车修复 × 刷资源** | 停车期间照常刷怪 → 玩家故意停着刷 | 停车期间刷新率 -60%，且资源掉落减半 |
